Verification-gated multi-agent orchestration architecture

This week's arxiv-prospector triage scored several papers on harness/orchestration design, with parallel 'voice' agents specifically assessing their orchestration-pattern signal.

  • A recurring pattern across the surfaced papers: keep the agent that proposes an action separate from the agent that certifies it (proposer != certifier), gated by a centralized admission check before work is accepted.
  • A shared 'claim-graph'/blackboard state plus a task-graph split lets agents hand work across models while making it possible to measure whether the handoff added real value, versus just added cost.
  • Strict parent-child message contracts with a single-owner rule for cross-cutting concerns (and upward escalation of unresolved defects) beat forwarding full conversation history, which one paper found buys cost, not accuracy.
  • Production-oriented write-ups converge on the same shape: plan -> execute -> verify -> replan loops with explicit boolean exit gates rather than freeform agent-to-agent chatter.

Global Workspace Theory as a lens for agent architecture

One triaged paper's memory-routing design was flagged by a dedicated review pass as a strong structural match for Bernard Baars' Global Workspace Theory (GWT).

  • GWT models cognition as specialized processors competing for access to a capacity-limited shared workspace; whichever signal wins gets 'broadcast' globally to every other processor.
  • Translated into agent-system design: use a bounded shared-state layer with an explicit write/admission gate (what's allowed in) and a separate retrieval/broadcast gate (what gets read back out), instead of letting every agent see every message.
  • This is now an active research thread, not just a metaphor — a 2026 'Theater of Mind' cognitive-architecture paper and reported Anthropic interpretability work both look for GWT-like structure actually emerging inside LLM-based systems.
Further reading
  • "Theater of Mind" for LLMs: A Cognitive Architecture Based on Global Workspace Theory
  • Global workspace theory

Efficient inference for vision-language models

A triaged paper claimed a first lossless one-pass speculative decoder for VLMs (2.93x speedup), prompting a look at where that technique sits in the current field.

  • Speculative decoding drafts several candidate tokens with a cheap model, then verifies them against the full model in one pass, cutting autoregressive steps while 'lossless' variants preserve the exact output distribution.
  • Vision-language models complicate this: the prefill stage is dominated by visual tokens whose count scales with image resolution or video length, inflating compute and KV-cache size well beyond a text-only LLM.
  • Because of that, vision-aware drafting (rather than treating image tokens like any other token) is the current edge — recent systems report 2.5-2.9x end-to-end speedups from making the draft model itself vision-aware.
Further reading
  • SpecVLM: Fast Speculative Decoding in Vision-Language Models
  • ViSpec: Accelerating Vision-Language Models with Vision-Aware Speculative Decoding
  • Multimodal Models Speculative Decoding Survey

Cross-model KV-cache transfer

A triaged paper proposed transferring KV cache between related models to skip prefill, worth situating against the broader inference-efficiency literature.

  • Systems that swap between different-sized models in a family (cost/quality cascading, mid-conversation model switching) normally repay the full prefill cost on every swap; KV-cache transfer is aimed at avoiding that.
  • One recent approach found KV representations are related by a closed-form linear mapping across matched model pairs (same head count and per-head dimension), with rotary position embeddings stripped out first so the mapping stays position-free.
  • Reported results: the linear mapper keeps 73-98% of standalone-prefill accuracy on most tested pairs and runs 2.7-25x faster than re-prefill, but degrades sharply on some pairs, so it isn't yet a universal drop-in.
Further reading
  • Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse
  • A Universal Context-Reuse Layer for Cross-Model KV Sharing

Systematic evaluation of research-paper claims

This week's paper triage deliberately ran separate parallel passes scoring veracity, novelty, buildability, capability, and optimization signal for each paper before deciding what to promote.

  • Treat novelty and soundness/veracity as separate axes: novelty asks whether a claim is new relative to prior work, soundness asks whether the method and evidence actually support the claim as stated.
  • Good practice traces every claim in a paper's introduction back to specific evidence in its methods and results, rather than trusting the framing -- this is how a paper that honestly labels itself 'preliminary' can still be caught overclaiming elsewhere in the text.
  • LLM-based paper review is itself an active research area (rubric-based reproducibility scoring, claim-decomposition novelty checks), but researchers still flag 'LLM judging LLM' circularity as an open reliability caveat.

Auditing Claude Code session efficiency

The weekly session-reflection run explicitly hunted for wasted tokens, repeated mistakes, and missing automation across the operator's own Claude Code sessions.

  • Token waste concentrates in a few recurring spots: vague prompts that trigger open-ended repo exploration, and noisy tool output (long grep/test/log dumps) that stays in context for the rest of the session.
  • Practical countermeasures: clear context between unrelated tasks, reference files directly instead of asking the agent to search for them, and route noisy commands through a subagent or quiet flags so their output doesn't pollute the main thread.
  • Prompt specificity is a bigger lever than model choice for most coding tasks -- a well-scoped first message cuts cost more reliably than switching models.
