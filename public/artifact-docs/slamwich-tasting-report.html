What 84 rebuilds of 28 acclaimed portfolios teach about design

Every dish in the kitchen renders the same content — design is the only variable. That makes the corpus a controlled experiment in what actually produces visual identity. This is the aggregate: the shared traits, the technique leaderboard, twelve specimens worth studying closely, and where to spend your attention.

This page practices what the corpus preaches: token-driven light/dark themes, a barbell type scale, one red accent, zero image assets. The header's ghost wordmark is Bleibtgleich's move.

§1

What the acclaimed 28 have in common

The references span wildly different worlds — a WebGL game, a 1998 frameset, an illuminated codex, a DOS boot screen. But strip the surfaces and the same six properties keep appearing:

  • One organizing idea, pushed all the way down. Every site is a thesis, not a theme: Shantell Martin is one continuous line, Rudnick is a black void of artifacts, Nicky Case is a page inside a speech bubble, Matuschak is sliding panes of thought. The idea governs layout, type, color, and interaction simultaneously. Nothing in the corpus reads as "a nice template plus personality sprinkles."
  • Constraint is the style. Daiki Fujita runs literally two colors (the rebuild enforces it with a regex test over the stylesheet). Pacôme, Holman, and Pipkin each use one typeface family. Zhenya spends one red. The corpus suggests identity comes from what you refuse, not what you add.
  • Typography does the heavy lifting. In 84 dishes the single biggest visual differentiator is display type: its face, its scale contrast against tiny tracked labels (the "barbell" — huge serif or grotesque vs 11px caps, nothing in between), and its treatments (stroke, extrusion, clipping). Color is a distant second.
  • Zero-asset confidence. The acclaimed look almost never depends on photography. Wood grain, CRT glass, riveted steel, paper, starfields, pixel sprites, clay — all rebuilt from gradients, box-shadow, borders, and SVG. Materials are cheaper than they look.
  • Motion character lives in timing functions, not quantity. steps() makes things read as electronics or physical mechanisms; overshoot beziers make them read as playful; expo-out reads as precision. Several top dishes (Rudnick, Bremer, Pipkin) are almost or entirely static — stillness is also a choice.
  • The best sites let you touch them. Poke the portrait, drag the letters, type into the masthead, scrub the timeline, resize the frames. Interactivity is the personality layer the screenshots miss — and every one of those toys ships an escape hatch so the content still works.

§3

Twelve specimens worth studying closely

The most interesting individual findings, each viewable live (bun run dev in ~/code/slamwich, then the link) with a full write-up in docs/dishes/<slug>.md.

variable fonts

Kinetic type by interpolating real letterforms

Mat Voyce's squash effect transitions font-variation-settings per character, staggered with nth-child transition delays so a wave rolls through the word. Interpolating actual outlines (width/weight axes) beats scaleX() categorically — strokes keep their proportions.

→ mat-voyce-faithful

type as data

A bitmap font in forty lines of strings

Holman's wildcard defines 37 glyphs as 5×7 grids of '1'/'0' strings — the letters are visible in the source code. Every cell always holds a character from the page's own copy; the glyph is a lighting state (unlit = transparent fill + 1px text-stroke, lit = white + neon shadow ladder). One matrix holds both a shape and a sentence.

→ tim-holman-wildcard · sibling remix models letterforms as arrays of positioned bars

svg economy

Thousands of dots as one path

Fujita's point-fields draw as a single <path> of zero-length subpaths (M x y h.01) with stroke-linecap: round — one DOM node per density layer instead of thousands of circles, and each layer still styles independently. The same dish enforces its two-color palette with a regex test over the stylesheet.

→ daiki-fujita-faithful

clip-path

A page rendered twice, cut mid-glyph

Fujita's wildcard renders the entire page in both polarities (black-on-white and white-on-black) and clips the top copy with a scroll-driven clip-path polygon. Blend modes can't cut cleanly through text; two DOM layers and a polygon can. display: flow-root on both layers keeps margin collapse from desyncing the copies.

→ daiki-fujita-wildcard

css math

Isometric projection in two calc() expressions

elle's walkable room passes tile coordinates as --c/--r custom properties; two calc() expressions project them to screen position and z-index: calc(10 + c + r) gives painter's ordering for free. The wildcard sibling lights the whole scene through ~18 tokens per [data-phase] — including shadow direction as a token that tracks the sun across the day.

→ ellesho-remix · ellesho-wildcard

css scheduling

A boot sequence scheduled entirely in CSS

Heffernan's remix sequences a BIOS boot log with a 0.01s step-end animation per line and calc()-derived delays from an index custom property — a pure-CSS scheduler, no JavaScript timers. The faithful sibling makes the simulated monitor its own viewport with container-type: inline-size + cqi units, which is the correct general answer for any nested device screen.

→ henry-heffernan-remix · henry-heffernan-faithful

svg filters

Hand-inked wobble on a geometric border

Nicky Case's speech bubble is a plain border on a ::before with inset: 0, distorted by feTurbulence + feDisplacementMap at two noise scales — so the SVG filter warps the outline without ever touching the text. Detail that matters: the filter defs stay in-flow at width/height: 0, because display: none would break url(#id) references.

→ nicky-case-faithful

fake 3d

A five-plane room with no preserve-3d

Giulio's remix builds a perspective room from five planes, each rotated then pushed back along its own local axis — no transform-style: preserve-3d, no scene graph. The animated grid streams on an inner child so the 3D-transformed parent never repaints. The wildcard sibling is the corpus's cleanest parallax rig: sticky stage over a tall wrapper, one scroll-derived --p, per-layer depth multipliers into one shared translate3d formula.

→ giulio-collesei-remix · giulio-collesei-wildcard

state cascade

A page that ages through one attribute

Melonking's wildcard rots in five stages driven by a single data-melon-stage on the root — attribute selectors cascade cracks, hue-rotate decay (scoped to decorative subtrees only), and an accelerating marquee. No JavaScript touches styling; JS moves one attribute and CSS does the rest. The same pattern powers Neal's clicker economy and elle's day/night.

→ melonking-wildcard

determinism

Generative identity seeded from the content itself

Bremer's three dishes hash persona strings (FNV-1a) into a PRNG (mulberry32) that drives triangulated mesh art — unique per dataset, byte-identical per render, and therefore testable. Voyce's wildcard seeds spring mass/stiffness per draggable letter the same way. Randomness that survives re-renders and screenshots is a superpower for generative branding.

→ nadieh-bremer-faithful · mat-voyce-wildcard

typesetting

A flex item as a controllable line break

Bleibtgleich's remix treats responsive typesetting as the entire subject: a zero-height flex item with flex: 0 0 var(--b) toggles between 0 and 100% to decide exactly where a headline breaks — recomposition without touching markup. Four composition sets tear one identical markup four ways.

→ maksym-bleibtgleich-remix

color science

A palette that rotates without breaking contrast

Comeau's wildcard authors accents in oklch() with hue as a custom property: calc(BASE + var(--hue-shift)) rotates the whole palette 360° while lightness — and therefore every contrast ratio — holds fixed. The faithful sibling registers color tokens with @property so even gradients tween on theme change.

→ josh-comeau-wildcard · josh-comeau-faithful

Honorable mentions: Rudnick's faithful ships zero animation on purpose and reads as authority; Pipkin's remix implements window-manager drag correctly (pointer listeners on window, never the 7px handle); Shantell's wildcard turns the visitor's own drawn stroke into an SVG <pattern> wallpaper; Pacôme's wildcard restyles a native <input type=range> into a DAW playhead and gets keyboard + ARIA for free.

§4

Where to spend your attention

Ranked by leverage: how often the skill appeared across 84 dishes, weighted by how much of the visual result it explains. Each item names the dishes to study and a concrete drill.

Tier 1 · foundations — most of the visible result

Tokens, type, and restraint

  • Custom properties as the design system's runtime. Colors, spacing, shadow direction, timing functions, even border-style live in tokens; state lives in data-* attributes; themes are token redefinitions under one selector. This is the single most common pattern in the corpus (~40 dishes) and the cheapest route to looking deliberate. drill Rebuild any page you own with a [data-mode] flip à la zhenya-rynzhuk-faithful, then push it to lynn-fisher-wildcard's full identity swap — fonts, alignment, and border-style as tokens, not just colors.
  • Typography first: one display face, one body face, a barbell scale. Huge display against 11px tracked caps with nothing in the middle is what makes pages read editorial instead of corporate. Then the treatment kit: -webkit-text-stroke outlines, stacked shadow extrusion, background-clip: text, box-decoration-break: clone for wrapping marks. drill A one-page specimen of your own name in five corpus treatments: Voyce's variable-font squash, Holman's neon ladder, Mantia's candy extrusion, Rudnick's chrome clip-text, Hische's em-unit letterpress.
  • Palette constraint: ground + ink + one accent. Nearly every acclaimed reference spends exactly one hot hue. Derive middle tones with color-mix() instead of adding hues. drill Fujita-remix's discipline: reduce a page to two color custom properties, generate every intermediate with color-mix(), and write the test that fails when a third hue sneaks in.

Tier 2 · craft multipliers — the texture of quality

Layout safety, painted surfaces, motion with intent

  • The modern layout kit, including the guards. repeat(auto-fit, minmax(min(100%, 20rem), 1fr)) grids that can't overflow; grid-area: 1/1 stacking instead of absolute positioning; gap-over-background as rules; grid-template-rows: 0fr→1fr for animating to auto height; overflow-x: clip (not hidden — it preserves position: sticky); container queries with cqi for anything that is its own little viewport. drill Build heffernan-faithful's nested screen: a component that scales purely from its container via cqi, then break it on purpose with vw to feel the difference.
  • CSS-built artwork. Stacked gradients for materials (leonardi's steel/water/chevron), box-shadow as a sprite rasterizer (melonking, elle), 8-value border-radius for organic shapes, feTurbulence for hand-drawn wobble. Zero requests, fully themeable, diffable as text. drill Take a page with images and replace every one with painted CSS/SVG. Steal zhenya-faithful's trick: abstract gradient compositions beat gray placeholder boxes.
  • Motion where the character is the timing function. steps() for machinery, overshoot beziers for play, expo-out for precision; scroll rigs as sticky + one custom property; React key-remount to replay one-shot animations; know that a running animation owns transform and will silently kill a transition on the same property (glander-remix splits them across parent and child). Declare animations inside @media (prefers-reduced-motion: no-preference) so stillness is the default, not an override. drill Build giulio-wildcard's rig: sticky stage, tall wrapper, one --p written from a rAF scroll handler, three layers moving at different depth multipliers.

Tier 3 · differentiators — what makes work memorable

SVG fluency, seeded generativity, accessibility as material

  • The SVG power set. pathLength="1" (any path becomes a 0–1 progress dial); transform-box: fill-box (rotate groups about their own center — mandatory before animating inside an SVG); vector-effect: non-scaling-stroke; preserveAspectRatio's slice/none as crop-vs-stretch art direction; runtime <pattern> swaps. drill Draw your logo as a path and scroll-draw it with pathLength=1 + stroke-dashoffset, shantell-remix style — then regenerate the path and watch the progress dial survive.
  • Seeded generative identity. String hash → tiny PRNG → art. Deterministic, testable, personal. drill Bremer-faithful's pipeline on your own name: FNV-1a → mulberry32 → a triangulated hero mark, with a test asserting byte-identical SVG output.
  • Accessibility as a design material, not a checklist. Style from ARIA state ([aria-expanded], [aria-pressed]) so visual and accessible state are the same fact; make the focus ring an idiom of the design (heffernan-wildcard's DOS highlight bar is the focus ring); live regions narrating visual toys (holman-wildcard announces what the masthead spells). drill Rudnick-wildcard's rule: build a disclosure interface where the only style hook is the ARIA attribute. No state classes allowed.
  • And the meta-skill: pick one organizing idea per project and commit. The corpus's clearest lesson isn't a property — it's that every acclaimed site can be described in one sentence, and every design decision serves that sentence. drill Before your next build, write the sentence first. Kill any element that doesn't serve it.
