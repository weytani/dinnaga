01

Problem first

Least complicated architecture that works.

completions / next edit
Mechanical, in-flow changes. Start here.
chat — ask mode
Questions and explanations. No edits yet.
edit mode
Scoped multi-file changes you watch land.
agent mode / Copilot CLI
Goal-driven local runs, tool approvals on.
cloud agent
Assign an issue, get a draft PR. Last rung, not first.
premium requests
The ladder is also the meter — each rung and model bills differently.
02

Focused context

Only relevant, authoritative context — retrieved, cited, fresh.

.github/copilot-instructions.md
Repo-wide. Short and authoritative — it rides in every request.
.github/instructions/*.instructions.md
Path-scoped rules via applyTo globs.
AGENTS.md
Root + nested; the cloud agent reads these (and CLAUDE.md).
*.prompt.md
Reusable task prompts, versioned like code.
Copilot Spaces
Curated grounding bundle per subject — not the whole org.
content exclusion
Keep secrets and noise out of context entirely.
new chat
Session gone noisy? Distill, then start clean.
03

Generate ≠ verify

Fluent is not verified: retrieve → generate → validate → review → act.

draft PR
Cloud-agent output is a proposal, never a landing.
required status checks
CI is the deterministic verifier. Make it required.
Approve and run workflows
Actions stay off until a human with write access clicks.
Copilot code review
A first pass — never the approving review.
copilot-setup-steps.yml
Preinstall deps so the agent iterates against real tests, not vibes.
04

Evals before scale

A representative eval set: common, hard, adversarial, previously failed.

golden suite
Agent work passes the same required checks you do.
regression prompts
Issues it fumbled become fixtures. Re-run them.
metrics API / usage reports
Acceptance rate and premium spend, per model.
review-comment rate
Human corrections per Copilot PR is your real quality metric.
instructions are code
PR and review every change to instructions and prompt files.
05

Human checkpoints

Review where direction is cheap to change.

the issue
Acceptance criteria before assigning — the spec is the first checkpoint.
session logs
Watch the plan form early; steer with PR comments while it's cheap.
ready for review
The agent can't flip it. A human promotes the draft.
required approvals
The requester can't approve the agent's PR — four eyes survive.
merge
Always yours. The agent cannot.
06

Least agency

No more capability, autonomy, duration, or access than the task requires.

copilot/* branches
The only place it can push. Protections still apply.
no Actions secrets
The runtime has none — don't hand them back via MCP config.
per-repo enablement
Turn the cloud agent on where needed, not org-wide.
custom agents
Scope toolsets per job in .github/agents/*.md.
tool approvals
Agent mode: allowlist narrowly. No blanket auto-approve.
org policy
Gate features and models centrally. Instructions are not access controls.
07

Zero trust

Model output and retrieved content are potentially hostile.

injection surfaces
Issue bodies, comments, docs, MCP tool descriptions — all untrusted input.
firewall
Outbound net is allowlisted by default. Extend it; don't disable it.
MCP allowlist
Third-party servers are supply chain: registry, pin, review.
secret scanning + push protection
Backstops behind the agent, not instead of care.
diff review for exfil
New URLs, encoded blobs, odd test fetches — read the diff.
08

Recoverable side effects

Side effects visible, approved, reversible; success read back from the system.

everything is a diff
The draft PR is the staging area; recovery is git revert.
no self-merge
Nothing lands without a human.
green before done
Read back the checks, not the model's claim of success.
edit checkpoints
In VS Code, keep/undo per file — review before keep.
09

Observability

Record enough to reconstruct what happened.

audit log
Copilot events land in the org audit log.
session logs
Step-by-step transcript of every cloud-agent run.
usage reports
Premium requests by user, model, and feature.
git provenance
Co-authored commits; instructions at a SHA. The whole chain replays.
10

Plan for change

Models time out, drift, regress, and get replaced. Build for it.

budgets
Cap premium spend; hard-stop at the cap.
model policies
Pin the roster — defaults drift under you.
re-run the goldens
Every model swap is a release. Test it like one.
downshift
Timeouts and refusals: drop a rung, not your standards.
no-Copilot path
CI + humans must still ship when the model is down.
11

Privacy & IP

Know where your data goes; minimize and redact before it leaves.

Business / Enterprise plans
Prompts and suggestions stay out of model training.
content exclusion
Sensitive paths never enter a prompt.
public code filter
Block matches; code referencing for license hygiene.
no secrets in chat
Redact before prompting — scanning is the net, not the norm.
12

Calibrated trust

Confidence and polish are not correctness.

read before accept
Completions are drafts, not decisions.
demand grounding
Attach files; ask for line citations; verify them.
"done" isn't
Run it. Green checks plus your eyes decide.
spec quality in, PR quality out
Teach issue-writing — the issue is the prompt.

OPERATING PRINCIPLE

Smallest Copilot surface that solves it · versioned, authoritative instructions · CI and humans declare success, never the model · the agent stays fenced to draft PRs on its own branch · watch the meters · re-test on every model change.
