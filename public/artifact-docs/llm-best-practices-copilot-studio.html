01

Problem first

Least complicated architecture that works.

topics
Known intents get deterministic dialogs. Start here.
generative answers
Only for the long tail, over named knowledge.
tools — connectors / flows
When the agent must act, not just answer.
generative orchestration
Turn on only when routing genuinely needs a model.
autonomous triggers
Event-driven runs: last rung, most guardrails.
Copilot Credits
The ladder is also the meter — classic < generative < actions < AI tools.
02

Focused context

Only relevant, authoritative context — retrieved, cited, fresh.

named knowledge sources
The authoritative SharePoint site, Dataverse tables, files. Never "everything".
general knowledge: off
When answers must come from your sources only.
agent instructions
Short and authoritative — retrieval happens per query, not in the prompt.
citations on
Generative answers cite their sources. Keep them visible.
per-topic knowledge
Scope sources to the topics that need them.
03

Generate ≠ verify

Fluent is not verified: retrieve → generate → validate → review → act.

entities + slot filling
Parse structured inputs deterministically before acting.
connectors read the record
Answer from the system of record, never model memory.
content moderation: high
On every generative answers node.
flows do the math
Deterministic work lives in Power Automate, not in prose.
adaptive cards
Constrain output shape where shape matters.
04

Evals before scale

A representative eval set: common, hard, adversarial, previously failed.

Copilot Studio Kit
Automated test sets: utterance → expected topic and answer.
adversarial rows
Off-topic, injection, and should-refuse cases belong in the set.
transcripts → fixtures
Mine failed conversations; add them to the suite.
analytics as gates
Resolution, escalation, abandonment, CSAT — release criteria, not trivia.
re-test before publish
Every time.
05

Human checkpoints

Review where direction is cheap to change.

Approvals
A Power Automate approval before any consequential action.
escalate topic
Hand off to a live agent with full conversation context.
test pane first
Publish is a deliberate act, not a save button.
autonomous review queue
Triggered runs propose; humans dispose.
06

Least agency

No more capability, autonomy, duration, or access than the task requires.

Entra Agent ID
Per-agent identity scopes Conditional Access and DLP to one agent.
end-user authentication
The agent acts as the user — never as the maker.
maker-credential lockdown
Forbid maker-credential passthrough on shared agents.
connector allowlists
DLP / Advanced Connector Policies: deny by default.
endpoint filtering
Custom connector + MCP egress pinned to known hosts.
capability toggles
Hosted browser and computer use stay off unless the task demands them.
07

Zero trust

Model output and retrieved content are potentially hostile.

require authentication
A no-auth agent over sensitive knowledge is the classic hole.
sensitivity labels
Labels travel with data; encrypted content stays unprocessable.
Purview DLP
Block responses that match sensitive-info types.
MCP = supply chain
External servers and agents: allowlist, review, monitor.
built-in injection defense
Classifiers exist. Never rely on them alone.
08

Recoverable side effects

Side effects visible, approved, reversible; success read back from the system.

show inputs
The user confirms tool inputs before the call runs.
Approvals on irreversibles
Payment, deletion, external mail: gated.
draft-then-publish flows
Stage writes; a human flips them live.
read-back
After a write, query the record and answer from it.
09

Observability

Record enough to reconstruct what happened.

Purview audit
Interaction metadata plus lifecycle events — who edited, who published.
DSPM for AI
Prompt/response content and sensitive-data detection.
Application Insights
Per-agent telemetry: topic hits, latency, errors.
Dataverse transcripts
Full text, 30-day default retention — set yours deliberately.
PPAC consumption
Credit burn per agent.
Sentinel
Alerting and automated response on agent signals.
10

Plan for change

Models time out, drift, regress, and get replaced. Build for it.

fallback topic
"I don't know" is an answer. Never freewheel.
solutions + pipelines
Dev → test → prod; rollback is an import away.
model updates = releases
Re-run the test kit when the platform rotates models.
credit alerts
High-traffic generative channels are cost surprises. Watch PPAC.
escalation survives outages
The human path works when the model doesn't.
11

Privacy & IP

Know where your data goes; minimize and redact before it leaves.

no training on your data
Enterprise content doesn't train foundation models.
service boundary
Processing stays in the Microsoft 365 trust boundary; EU Data Boundary where applicable.
transcripts are records
Retention, eDiscovery, and Communication Compliance apply.
minimum knowledge
Connect what the agent needs. Nothing more.
maker visibility toggles
Decide deliberately who can read user conversations.
12

Calibrated trust

Confidence and polish are not correctness.

test pane ≠ production
Channels, auth, and DLP all change behavior. Test published.
teach the citations
Users click sources; confident prose isn't evidence.
CSAT + escalation trend
Your live trust meters — watch the trend, not the demo.
credentials never in chat
Auth flows exist; prose is not a login form.

OPERATING PRINCIPLE

Topics before orchestration, orchestration before autonomy · every answer grounded in named knowledge · connectors and flows touch systems of record, never the model directly · one agent, one identity, one scope · watch transcripts, credits, and audits · every model rotation gets its tests re-run.
